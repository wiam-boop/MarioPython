# 🎮 MarioPython

لعبة **Platformer** مطوّرة باستخدام **Python** و **Pygame**. يتحكم اللاعب
بالشخصية، يقفز فوق المنصات، يجمع العملات، يتعامل مع الأعداء، ويتقدم حتى
يصل إلى نهاية المرحلة ويفوز.

## ✨ المميزات

-   🏃 حركة يمين ويسار
-   🦘 القفز والجاذبية
-   🧱 المنصات والتصادمات
-   👾 أعداء متحركون
-   💥 القضاء على الأعداء بالقفز فوقهم
-   🪙 جمع العملات والنقاط
-   ❤️ نظام الأرواح
-   📷 كاميرا تتبع اللاعب
-   🎞️ Animations للحركة والقفز والسقوط
-   🎵 موسيقى ومؤثرات صوتية
-   🏰 هدف ونهاية للمرحلة
-   🏆 شاشة فوز و 💀 Game Over

## 🛠️ التقنيات

-   **Python 3.13**
-   **Pygame**

### وظيفة الملفات الأساسية

  الملف                الوظيفة
  -------------------- ---------------------------------------
  `main.py`            تشغيل اللعبة وربط الأنظمة معًا
  `settings.py`        إعدادات الشاشة والـFPS والألوان
  `player.py`          حركة اللاعب والقفز والجاذبية والتصادم
  `enemy.py`           إنشاء الأعداء وحركتهم
  `level.py`           بناء المرحلة ووضع العناصر
  `camera.py`          تحريك الكاميرا مع اللاعب
  `coin.py`            العملات وجمعها
  `goal.py`            نهاية المرحلة والفوز
  `sound_manager.py`   الموسيقى والمؤثرات الصوتية
  `animations.py`      تشغيل إطارات الحركة
  `background.py`      إدارة الخلفية
  `game_state.py`      الأرواح والنقاط والفوز والخسارة
  `image_utils.py`     أدوات مساعدة للصور

## ⚙️ التثبيت

تأكد من تثبيت Python، ثم افتح Terminal داخل مجلد المشروع وشغّل:

``` bash
pip install pygame
```

## ▶️ تشغيل اللعبة

من داخل مجلد `MarioPython`:

``` bash
python main.py
```

إذا كان الأمر `python` غير متاح على جهازك، جرّب:

``` bash
py main.py
```

## 🎮 التحكم

  الزر    الوظيفة
  ------- ------------------------------------
  ⬅️      التحرك يسارًا
  ➡️      التحرك يمينًا
  Space   القفز
  R       إعادة التشغيل بعد الفوز أو الخسارة
  ESC     الخروج

## 🏆 طريقة اللعب

ابدأ المرحلة، تحرك بين المنصات، اجمع العملات، وتجنب الأعداء. يمكنك
القضاء على العدو بالقفز فوقه. واصل التقدم حتى تصل إلى الهدف في نهاية
المرحلة.

لديك **3 أرواح**، وعند خسارتها جميعًا تظهر شاشة **Game Over**.

## 🔊 الأصوات

تستخدم اللعبة موسيقى خلفية ومؤثرات لجمع العملات، القضاء على الأعداء،
الاصطدام، الفوز والخسارة. يجب وضع ملفات الصوت داخل:

``` text
assets/sounds/
```

## 🖼️ الصور

توضع Assets الخاصة باللعبة داخل:

``` text
assets/images/
```
